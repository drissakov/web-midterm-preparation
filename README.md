# JavaScript Practice

A standalone Russian-language JavaScript theory and multiple-choice trainer.

Live website: [JavaScript Practice](https://drissakov.github.io/web-midterm-preparation/).

- 36 questions across six topics.
- Four choices and one correct answer per question.
- Answer explanations, results, and retrying mistakes.
- Six short theory lessons and topic search.
- No backend, external asset dependencies, or package installation.

## Run

Open `index.html` in a modern browser, or serve this directory with a static HTTP server. Keep the `css`, `js`, and `images` directories next to the entry page.

## Publish

GitHub Pages publishes the root of the `main` branch. All asset links are relative, so the same files work at the domain root and beneath a repository path. The `.nojekyll` file keeps static files unchanged during GitHub Pages publication.
